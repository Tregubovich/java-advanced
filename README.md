# Java Advanced — домашние задания

Набор домашних заданий по курсу **Java Advanced**, посвящённых коллекциям, Stream API, многопоточности, сетевому программированию, RMI, генерации кода и локализации.

## Домашние задания

### [Walk](/java-solutions/info/kgeorgiy/ja/tregubovich/walk)

Рекурсивный обход файлов и директорий с вычислением их хэш-сумм.

### [ArraySet](/java-solutions/info/kgeorgiy/ja/tregubovich/arrayset)

Реализация неизменяемого упорядоченного множества на основе массива с эффективными операциями над множествами.

### [Student](/java-solutions/info/kgeorgiy/ja/tregubovich/student)

Работа с базой данных студентов с использованием лямбда-выражений и Stream API.

### [Streams](/java-solutions/info/kgeorgiy/ja/tregubovich/streams)

Реализация собственных сплитераторов и коллекторов для работы с потоками и деревьями.

### [Implementor](/java-solutions/info/kgeorgiy/ja/tregubovich/implementor)

Генерация исходного кода реализаций произвольных классов и интерфейсов Java.

### [Iterative](/java-solutions/info/kgeorgiy/ja/tregubovich/iterative)

Параллельная обработка коллекций с использованием нескольких потоков без стандартных средств `Concurrency Utilities`.

### [Hello](/java-solutions/info/kgeorgiy/ja/tregubovich/hello)

Реализация UDP-клиента и сервера с поддержкой параллельной обработки запросов.

### [Bank](/java-solutions/info/kgeorgiy/ja/tregubovich/bank)

Распределённое банковское приложение с удалёнными и локальными представлениями физических лиц и их счетов.

### [Crawler](/java-solutions/info/kgeorgiy/ja/tregubovich/crawler)

Потокобезопасный многопоточный веб-краулер с ограничением числа загрузок и обработчиков ссылок.

### [I18n](/java-solutions/info/kgeorgiy/ja/tregubovich/i18n)

Приложение для статистического анализа текста на разных языках с поддержкой локализации результатов.
